# Elenta Office — live floor (v2 app shell)

Interactive isometric office built on the devs' asset pack (elenta-office-assets-v2):
the v2 app chrome (nav, org rail, New job / Needs you / Running panel, budgets,
legend) with a live SVG floor. Click a room to open the department; click a
worker for their status card. Status rings and sidebar counts derive from the
same `people` data. Pan/zoom, rotate, light/dark.

Published artifact: https://claude.ai/artifact/47rrEsphiwhefsKytGWJSH
Assets are AI-generated illustrations from the dev pack (PNG workstations,
SVG screens/markers). Sample agent state — not wired to a live backend yet.
