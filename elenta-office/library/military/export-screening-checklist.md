# Export-screening checklist

Run this before any defence-domain deliverable leaves the office. It is a screening aid, not legal advice.

1. Does the deliverable describe controlled technology, performance figures or source code for a defence item? If yes, flag it.
2. Is a classification number (ECCN or national equivalent) recorded for the item? If not, mark "classification needed".
3. Is the recipient, and their country, known and recorded?
4. Are there technical drawings, algorithms or test data beyond what is needed for the purpose? Remove them or flag them.
5. Record the result as: **clear**, **flag for review**, or **stop**, with one sentence of reasoning.

Anything flagged goes to the export control officer before release.
