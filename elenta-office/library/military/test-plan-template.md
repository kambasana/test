# Test plan template

A test plan fits on one to three pages. Sections:

1. **Item under test** — name, version, and the baseline it belongs to.
2. **Objectives** — what the testing must show, tied to requirement ids.
3. **Test environment** — hardware, software, tools, and calibration status.
4. **Test cases** — table with: id (`TC-nnn`), requirement id(s), method (T/A/I/D), steps in short form, expected result, pass criterion.
5. **Traceability** — every requirement appears in at least one test case; list any that do not, with the reason.
6. **Entry and exit criteria** — what must be true before testing starts and when it is complete.
7. **Risks and assumptions** — mark assumptions *(assumed)*.

Test case ids are never reused, even when a case is deleted.
