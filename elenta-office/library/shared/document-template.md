# Document template

Use these sections for any formal document. Drop a section only if it truly does not apply.

1. **Title block** — title, document number, version, date, author, status (draft / for review / released).
2. **Purpose and scope** — two or three sentences: what this covers and what it does not.
3. **References** — documents this one depends on, by number and version.
4. **Body** — the content, in numbered sections.
5. **Open points** — questions still to be answered, each with an owner.
6. **Change record** — version, date, what changed, who changed it.

Document numbers follow `ELN-<DEPT>-<TYPE>-<NNN>`, for example `ELN-MIL-TP-014` for a military test plan.
