# Glossary

- **Acceptance criterion** — a condition a result must meet to be accepted, stated so it can be checked.
- **Baseline** — an agreed, versioned set of documents or code that changes only through a change record.
- **DUT** — device under test.
- **ECCN** — export control classification number, used to decide whether an item needs a licence.
- **RTM** — requirements traceability matrix: a table linking each requirement to its design and tests.
- **Shall / should / may** — mandatory / recommended / optional, in requirements text.
- **TBD** — to be decided; every TBD needs an owner and a date.
- **Verification method** — how a requirement is shown to be met: test (T), analysis (A), inspection (I) or demonstration (D).
