# House style

How Elenta writes, whatever the department.

- Lead with the answer. The first paragraph says what the reader needs to know or decide.
- Short sentences, active voice, one idea per paragraph.
- Use numbered lists for steps and tables for anything compared across more than two items.
- Dates as YYYY-MM-DD. Units in SI with a space before them (12 V, 250 ms).
- Name things the same way every time; define an abbreviation on first use and add it to the glossary.
- Mark anything you had to assume with *(assumed)* so a reviewer can check it.
- No marketing language. If a claim matters, say how it was checked.
